# 비로그인 사용자 접근 시 발생하는 NullPointerException(NPE) 해결

## 문제 상황
- 스터디 상세 페이지에 비로그인(게스트) 사용자가 URL을 직접 입력하여 접근 시, 세션에서 꺼내온 회원 객체가 `null`이 되어 NullPointerException(NPE)이 발생하고 서버가 다운됨

## 원인
- 상세 페이지 화면 렌더링 시 로그인 사용자의 '신청 여부'를 확인하기 위해 세션 객체(`loginMember`)를 참조하는데, 비로그인 상태일 경우 해당 객체가 `null`임에도 이에 대한 예외 처리가 누락됨

## 해결 방법
- 컨트롤러 로직에서 객체를 참조하기 전 `if (loginMember != null)` 조건문을 통해 세션 객체의 존재 여부를 1차로 검증하는 방어 로직을 추가
- 이를 통해 게스트 사용자도 에러 없이 정상적으로 화면을 렌더링할 수 있도록 서버 안정성을 확보함

## 배운 점
- 사용자는 항상 개발자가 의도한 정상적인 UI 흐름(버튼 클릭 등)으로만 접근하지 않으며, URL 직접 입력 등 예외적인 접근 방식이 존재함을 인지하게 되었습니다.
- 세션 데이터나 외부에서 주입받는 객체를 다룰 때는 항상 `null`일 가능성을 열어두고 1차 방어 로직(Null Check)을 작성하는 방어적 프로그래밍(Defensive Programming)의 중요성을 체감했습니다.
