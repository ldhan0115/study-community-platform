# 개념적 모델링 (Conceptual Data Modeling)

스터디/커뮤니티 플랫폼의 **핵심 도메인과 엔티티 관계를 정의한 개념적 모델링**

개념적 모델링 단계에서는 데이터 구조의 큰 틀을 정의한다.

---

# 1. 핵심 엔티티 도출

서비스 요구사항을 분석하여 다음과 같은 핵심 엔티티를 도출하였다.

| 엔티티 | 설명           |
|------|--------------|
| Member | 서비스를 사용하는 회원 |
| Study | 스터디 모집 게시글   |
| Application | 스터디 참여 신청    |
| Comment | 스터디에 대한 댓글   |

---

# 2. 엔티티 설명

## Member
서비스를 사용하는 사용자 정보를 저장하는 엔티티

주요 역할
- 회원가입
- 로그인
- 스터디 개설
- 댓글 작성
- 스터디 신청

---

## Study
스터디 모집 게시글을 의미한다.

회원은 스터디를 생성하여 다른 회원을 모집할 수 있다.

주요 기능
- 스터디 생성
- 모집 인원 관리
- 모집 상태 관리

---

## Application
회원이 특정 스터디에 참여하기 위해 신청하는 행위를 나타낸다.

주요 기능
- 스터디 참여 신청
- 신청 취소
- 스터디장의 승인 / 거절
- 신청 상태 관리

---

## Comment
스터디에 대한 댓글을 나타낸다.

주요 기능
- 댓글 작성
- 댓글 수정
- 댓글 삭제

---

# 3. 엔티티 관계

시스템에서 엔티티 간 관계는 다음과 같다.

| 관계                   | 설명                           |
|----------------------|------------------------------|
| Member - Study       | 한 회원은 여러 스터디를 개설할 수 있다 (1:N) |
| Member - Application | 한 회원은 여러 스터디에 신청할 수 있다 (1:N) |
| Study - Application  | 하나의 스터디에는 여러 신청이 존재한다 (1:N)  |
| Member - Comment     | 한 회원은 여러 댓글을 작성할 수 있다 (1:N)  |
| Study - Comment      | 하나의 스터디에는 여러 댓글이 존재한다 (1:N)  |

---

# 4. 주요 속성 정의

각 엔티티의 주요 속성은 다음과 같다.

## Member

| 속성    | 설명     |
|-------|--------|
| id    | 회원 식별자 |
| loginId | 로그인 ID |
| password | 비밀번호   |
| email | 이메일    |
| nickname | 닉네임    |
| createdAt | 생성일    |
| updatedAt | 수정일    |
| deletedAt | 삭제일    |

---

## Study

| 속성 | 설명           |
|----|--------------|
| id | 스터디 식별자      |
| title | 제목           |
| content | 내용           |
| method | 진행 방식        |
| region | 지역           |
| capacity | 모집 정원        |
| status | 모집 상태        |
| createdAt | 생성일          |
| updatedAt | 수정일          |
| deletedAt | 삭제일          |

---

## Application

| 속성        | 설명 |
|-----------|----|
| id        | 신청 식별자 |
| message   | 신청 메시지 |
| status    | 신청 상태 |
| createdAt | 생성일 |
| updatedAt | 수정일 |

---

## Comment

| 속성 | 설명          |
|----|-------------|
| id | 댓글 식별자      |
| content | 댓글 내용       |
| createdAt | 생성일         |
| updatedAt | 수정일         |
| deletedAt | 삭제일         |

---
